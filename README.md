# Hola, soy Daniel 👋

Desarrollador de software desde Chile 🇨🇱, en **Facepass SpA**.
Construyo sistemas de identificación biométrica y control de acceso: APIs en .NET, aplicaciones de escritorio y servicios que se integran con lectores de huellas y relojes biométricos.

## Qué hago

- **APIs REST** en ASP.NET Core con autenticación JWT, logging estructurado y documentación Swagger.
- **Apps de escritorio** en WPF con lectores de huellas, generación de certificados en PDF, instalador y actualización automática.
- **Integración con dispositivos biométricos** y con APIs de terceros, sincronizando marcajes y plantillas.
- **Bases de datos** SQL Server y PostgreSQL: modelado, migraciones y consultas.
- **Seguridad**: cifrado AES-256-GCM, hashing con BCrypt, gestión de secretos con Azure Key Vault.
- **Despliegue**: Docker, GitHub Actions y Azure.
